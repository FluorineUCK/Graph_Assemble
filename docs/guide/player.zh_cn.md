# 玩家使用指南

[English](player.md) | 简体中文

## 工件加工

将入口原料送入图中指定的机器，成功后得到携带进度的工件。工件提示显示本地化工序摘要；F3+H 可查看技术 ID 和完整停工诊断。合法工件只允许执行当前图的合法下一步；随机分支选定后会锁定，不会因查询或 `/reload` 重抽。抵达出口后按配方条件结算；没有匹配规则时，宽容出口保留工件并可继续沿出边加工，严格出口则按配置处理失败品。

在合并工序前，主、辅工件的提示都会列出对方所需的物品和已完成工序。辅工件就绪时不会再误报停工；合并后仍沿用主工件的进度。

## 图装配过滤器

生存模式可通过[内置过滤器教学配方](kubejs.zh_cn.md#13-内置图过滤器双工件教学配方)制作；测试时也可使用 `/give @s graph_assembly:graph_filter` 获取。右键打开选择界面，在配方行和工序行滚轮选择目标；“＋”添加正向条件（当前允许执行该工序），“!＋”添加反向条件（当前不允许执行该工序）。底部选择“任一 / 全部 / 排除”：分别表示任一条件成立、全部条件成立、没有条件成立（逐项取反后再组合）。同一工序不能同时添加正反条件。确认保存，Esc 取消；清空只改当前草稿，切换配方会清掉先前图的条件。

过滤器只匹配所选图的有效工件或合法入口原料，且必须存在可执行工序。失效配置、停工工件、其他图和无关物品不会因反向条件而被放行。无需 JEI 或输入技术 ID，也可放入 Create 过滤槽或普通过滤器内。

过滤条件按主工件判断；能参与合并的辅工件不因此成为可执行该工序的主工件。物品提示默认显示已保存条件，按住 Shift 查看使用概要，样式沿用 Create 原生过滤器。

## 容量与查看

单个过滤器最多包含 256 个去重目标；配方 ID 与节点 ID 各最多 1024 个 UTF-16 单位，配置 JSON 最多 16384 个 UTF-8 字节（含转义）。超限时确认不可用并显示原因；服务端也会校验，不会截断。

安装 JEI 后，可从原料用途或最终产物配方打开“图装配”预览。左上切换平面/球面；左键拖动平移或旋转，滚轮缩放，点击节点或边查看详情。结算说明列在 JEI 原生 Info 页。画布页脚的出口选择器会联动该出口的成功候选与严格失败池；候选较多时可通过 `+N` 展开，也可对物品槽查询配方或用途。预览仅供查看，显示原生配方不代表对应机器可执行图加工。

右上角的重置按钮恢复当前模式的初始视角和缩放，保留选中的节点、边与结算出口。`×` 和 `+N` 按钮不显示悬浮提示。
