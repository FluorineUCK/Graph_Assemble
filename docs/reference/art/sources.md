The reference asset is `assets/createfactorycontroller/textures/gui/controller_background/blueprint.png` from commit [`c345e06923cb7b905cbc8e06bb5bc28987d6c1da`](https://github.com/nbcss/create-factory-controller/commit/c345e06923cb7b905cbc8e06bb5bc28987d6c1da) in the Create Factory Controller repository.
